# 👋 Hi, I'm Miguel!

### 💻 Software Engineer

I am a Software Engineer and Computer Science graduate from the University of Las Palmas de Gran Canaria, where I studied from 2021 to 2025. I work on building software with a focus on clean, tested and maintainable code, and I enjoy working across the stack, from backend logic to user interfaces.

🌐 **Portfolio:** [miguelescsan.is-a.dev](https://miguelescsan.is-a.dev/inicio)

---

### 🚀 Main Projects

- [📅 **Teacher Duty Scheduler**](https://github.com/MiguelEscSan/teacher-duty-scheduler) - A scheduling system that automatically and fairly assigns teacher duty shifts in schools, respecting timetables, preferences and breaks. Built with Python, Angular, SQLite and Docker.
- [📊 **FinancialDistressPredictor**](https://github.com/MiguelEscSan/FinancialDistressPredictor) - Code for my bachelor's thesis, a study of the relationship between innovation and business outcomes in clothing and footwear retail companies using artificial intelligence.
- [📱 **UniMatch**](https://github.com/UniMatchApp) - A dating app designed for university students, fostering meaningful connections within the academic community.
